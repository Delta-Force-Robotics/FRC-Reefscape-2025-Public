# FRC Reefscape 2025

Robot code from Delta Force Robotics for the 2025 FIRST Robotics Competition game, *Reefscape*.

The robot uses a swerve drivetrain, a two-motor elevator with a pivoting arm and gripper for coral and algae, a ground coral intake with an indexer, and a deep cage climber.

## Built with

- [WPILib](https://docs.wpilib.org/) 2025 (Java, command-based)
- [CTRE Phoenix 6](https://v6.docs.ctr-electronics.com/) for the swerve drive, elevator and arm
- [REVLib](https://docs.revrobotics.com/revlib) for the intake, indexer, gripper and climber
- [PathPlanner](https://pathplanner.dev/) for autonomous routines
- [Limelight](https://docs.limelightvision.io/) for AprilTag-based reef alignment

## Layout

| Path | Contents |
| --- | --- |
| `src/main/java/frc/robot/Constants.java` | CAN IDs, gains and mechanism setpoints |
| `src/main/java/frc/robot/RobotContainer.java` | Controller bindings, scoring sequences and PathPlanner event markers |
| `src/main/java/frc/robot/ScoringTarget.java`, `AlgaePickup.java` | Selectable scoring and algae pickup locations with their elevator/arm setpoints |
| `src/main/java/frc/robot/subsystems/` | Drivetrain, elevator, arm, gripper, intake, indexer and climber |
| `src/main/java/frc/robot/commands/` | Limelight reef alignment |
| `src/main/java/frc/robot/generated/` | Swerve constants generated by Phoenix Tuner X |
| `src/main/deploy/pathplanner/` | Autonomous paths and routines |

## Controls

All controllers are PS5 controllers.

**Driver (port 0)**

| Input | Action |
| --- | --- |
| Left stick / right stick | Field-centric drive / rotate |
| Options | Reset field-centric heading |
| Cross | Deploy intake and wait for coral |
| Circle | Stow intake |
| Square | Pick up algae from the selected location |
| L1 | Raise to the selected scoring target |
| R1 | Score, back away and retract |
| L2 / R2 (hold) | Align to the left / right reef branch |
| D-pad left / right | Deploy climber / climb |

**Operator (port 1)**

| Input | Action |
| --- | --- |
| D-pad up / down | Select the next higher / lower scoring target (Processor, L1-L4, Barge) |
| Triangle / Cross | Select the next higher / lower algae pickup (Floor, L2, L3) |
| Circle | Stop and stow the intake |

**Climb backup (port 2):** Cross / Circle / Square run the climber up / stop / down open loop.

## Autonomous

Three routines are available from the `Auto Mode` chooser, all drawn for the blue alliance and mirrored automatically on red:

- `AutoBlueLeft` and `AutoBlueRight`: preload plus two coral from the coral stations, all on L4
- `AutoBlueMid`: preload on L4, then two algae from the reef scored in the barge

## Building

```bash
./gradlew build
```

Deploying requires the WPILib 2025 toolchain and a roboRIO. This code is published for reference and is no longer maintained or run on a robot.
